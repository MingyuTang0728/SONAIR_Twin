    Sensors

    LSM6DSV16X units read through their FIFO with the sensor's own timestamps. Each stream keeps its own clock; the session maps it to the host clock afterwards.

    Sessions

    A session records the robot at every controller cycle and every inertial unit on its own clock, then runs QC. A command moves the robot only through the executor: half speed by default, refused above 0.6 rad/s or if it failed the collision check.
